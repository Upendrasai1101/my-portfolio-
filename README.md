# 🤖 Upendra Sai Chaturvedula Portfolio

Professional portfolio website of **Upendra Sai Chaturvedula** — MCA Graduate, Full-Stack Developer & AI Engineer. Modern UI, colorful glassmorphism theme inspired by SaaS landing pages.

🔗 **Live Site:** [upendrasai1101.github.io/my-portfolio-](https://upendrasai1101.github.io/my-portfolio-/)

---

## ✨ Key Features

* 🎨 **Colorful Glassmorphism UI:** Dynamic animated gradient accents through CSS.
* 📱 **Fully Responsive:** Clean mobile menu toggle via JS.
* 🌀 **Scroll-Reveal Animations:** Fade-in on scroll (`IntersectionObserver`).
* ⚡ **Zero Build Step:** Instant load, single static HTML file.
* 📄 **Resume Download:** Directly available in header.
