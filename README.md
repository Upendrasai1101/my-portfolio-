## 📖 About

This is a single-page portfolio built to showcase my projects, technical skills, certifications, and education — with a resume available for direct download. Designed with a modern, colorful glassmorphism theme inspired by contemporary SaaS/tech landing pages.

## ✨ Features

- 🎨 Vibrant glassmorphism UI with animated gradient accents
- 📱 Fully responsive — mobile hamburger navigation included
- 🌀 Scroll-triggered fade-in animations (IntersectionObserver)
- 📄 One-click resume download (PDF)
- ⚡ Zero build step — single static HTML file, loads instantly
- 🧭 Smooth-scroll navigation across sections

## 🛠️ Tech Stack

- **HTML5** — semantic structure
- **Tailwind CSS** (via CDN) — utility-first styling
- **Custom CSS** — glassmorphism, gradients, keyframe animations
- **Vanilla JavaScript** — mobile menu toggle, scroll-reveal observer
- **Google Fonts** — Space Grotesk, Inter, JetBrains Mono

No frameworks, no build tools, no dependencies to install — just static files.
